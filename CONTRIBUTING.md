# Contributing to CANDEW
Are you interested in contributing to CANDEW? Have a read through the following sections to find out how :)

## New Features and Improvements
If you have an idea for a new feature or an improvement for CANDEW, then the "Ideas" category of the Discussions section is 
the place for you. This is a place where new ideas can be floated around and discussed. In the post, please make sure that you
provide a clear description of the idea, how it might work and why it should be added. If your idea is accepted, it will be 
added to CANDEW and you will receive credit for it.  

## Bugs and Errors
If you happen to stumble across any bugs or errors while using CANDEW, please don't hesitate to make a post about it in the 
"Issues" section with "BUG" or "ERROR" in the title. In the post, please make sure that you provide a clear description of what 
the bug/error is and how it is triggered.  

## Questions
If you have any questions, big or small, regarding CANDEW, please feel free to post it the in "Q&A" category of the Discussions 
section. Even if it is just a quick question, don't hesitate to ask. I'll try my best to make sure that I answer any questions as
soon as I can and as best as I can.  

## Feedback
Feedback is always appreciated, as it helps to improve CANDEW. If you would like to leave your feedback about the project,
you can do so in the "Feedback" category of the Discussions section.
